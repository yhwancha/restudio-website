# Cherpa 디자인 시스템 가이드라인 (`design.md`)

## 개요 (Overview)

**Cherpa(CMS, CRM + Sherpa)**의 웹 크레덴셜 및 인터페이스는 복잡한 관리 기능(CMS/CRM)을 '맞춤형 웹사이트 제작'이라는 서비스와 결합하여 직관적으로 제공합니다. 대시보드의 정밀함 및 에디토리얼 웹의 신뢰감이 공존하는 구조를 지향합니다.

기본 시각 언어는 무채색(Grays, White, Black) 중심의 고도로 정제된 톤앤매너를 사용합니다. 이를 통해 수많은 데이터와 복잡한 관리 기능을 다뤄야 하는 관리자가 시각적 피로감 없이 본연의 태스크에 집중할 수 있도록 돕습니다. 브랜드의 정체성을 드러내거나 사용자의 흐름을 가이드하는 **최고 수준의 강조 영역에만 `primary` 블루 컬러를 제한적으로 사용**하여 강력한 시각적 앵커를 형성합니다.

* **무채색 기반의 정돈된 인터페이스**: 화이트 스페이스와 섬세한 그레이 스케일 레이어를 통해 정보의 위계를 설계합니다.
* **제한적이고 명확한 Primary 사용**: 중요한 전환점(CTA) 및 핵심 안내 마커에만 유일한 강조색으로 블루를 사용합니다.
* **직관적인 모듈러 대시보드 레이아웃**: 복잡한 설정 화면이 하나의 정돈된 컴포넌트 카드처럼 유기적으로 맞물려 작동합니다.
* **신뢰감을 주는 위계 체계**: 디자인 토큰에 정의된 부드러운 DropShadow와 라운딩 값을 활용하여 세련된 SaaS 프로덕트의 터치를 구현합니다.

## 컬러 시스템 (Colors)

### 1. 브랜드 및 강조 (Brand & Accent)

* **Cherpa Black** (`#000000` / `black`): 글로벌 브랜드 앵커 및 최상위 타이포그래피의 기준점입니다.
* **Near-Black Primary** (`#171A20` / `gray.900`): 기본 본문 텍스트, 다크 모드 카드, 핵심 UI 요소의 베이스 컬러입니다.
* **Point Primary Blue** (`#3070E2` / `primary.600`): 대고객용 핵심 전환 CTA, 성공 지표 등 극도의 강조가 필요한 요소에만 한정 사용합니다.
* **Sub Action Blue** (`#508EFF` / `primary.500`): 호버 상태, 활성화된 메뉴 탭, 포커스 링의 보조 컬러로 쓰입니다.

### 2. 표면 및 배경 (Surface & Background)

* **Main Canvas White** (`#ffffff` / `white`): 지표 대시보드 배경, 기본 페이지 백드롭, 폼 필드 입력창 내부에 사용합니다.
* **Soft Card Surface** (`#FDFDFD` / `gray.25` 또는 `#FAFAFA` / `gray.50`): 메인 대시보드 위젯 카드 및 정보 블록의 배경입니다.
* **Section Layer Wash** (`#F5F5F5` / `gray.100` 또는 `#E9EAEB` / `gray.200`): 무채색 카드들 사이의 구분을 만들어주는 섹션 단위 음영 배경입니다.
* **Dashboard Mix Surface** (`#f8f9fc` / `blueGray.50`): CMS/CRM 데이터 밀집 영역에서 정돈된 인상을 주기 위해 종종 그레이와 조합하여 교차 적용합니다.

### 3. 텍스트 및 라인 (Text & Rules)

* **Text Main** (`#171A20` / `gray.900`): 가독성이 필요한 모든 메인 타이틀 및 본문 Copy 문맥에 매핑합니다.
* **Text Sub** (`#474B52` / `gray.700`): 서브 텍스트, 필드 라벨, 부가 설명문에 지정합니다.
* **Text Muted** (`#878B93` / `gray.500`): 플레이스홀더, 메타데이터, 비활성화된 레이블에 할당합니다.
* **Hairline Border** (`#D5D7DA` / `gray.300`): 테이블 구분선, 폼 테두리, 컴포넌트 경계선에 사용합니다.

## 타이포그래피 (Typography)

### 폰트 패밀리 (Font Family)

* **전체 시스템 서체**: `Pretendard`를 전역 적용합니다.
* **Fallback 서체**: `Inter`, `Arial`, `ui-sans-serif`, `system-ui` 순으로 대응합니다.
* **폰트 두께 상한**: 이 프로젝트에서는 ExtraBold를 사용하지 않습니다. 강조 타이포그래피의 최대 두께는 `SemiBold` / `600`입니다.

`Pretendard` 토큰 스케일에 맞춘 타이포그래피 체계입니다 (1rem = 16px 기준).

| 역할 (Role) | 토큰명 | 크기 (Size) | 두께 (Weight) | 행간 (Line Height) | 자간 (Letter Spacing) | 비고 |
| :--- | :--- | :---: | :---: | :---: | :---: | :--- |
| **Hero Display** | `d1sb` / `d1` | 80px | SemiBold / Regular | 140% | -1% | 메인 랜딩 페이지 캐치프레이즈 |
| **Section Title** | `h1sb` / `h1` | 60px | SemiBold / Regular | 140% | -1% | 대메뉴, 대형 기능 소개 타이틀 |
| **Module Title** | `h2sb` / `h2` | 40px | SemiBold / Regular | 150% | -2% | CMS/CRM 대시보드 카드 타이틀 |
| **Widget Heading** | `h3sb` / `h3` | 32px | SemiBold / Regular | 150% | -2% | 중형 컴포넌트, 가이드 가단 헤더 |
| **Card Header** | `h4sb` / `h4` | 24px | SemiBold / Regular | 150% | -2% | 리스트 그룹 제목, 폼 세션 타이틀 |
| **Item Title** | `h5sb` / `h5` | 20px | SemiBold / Regular | 150% | -3% | 테이블 셀 헤더, 모달 내부 타이틀 |

## 깊이감 및 그림자 (Elevation & Depth)

수많은 정보 계층을 명확히 분리하기 위해 디자인 토큰에 정의된 `dropShadow` 시스템을 활용합니다.

| 단계 (Level) | 적용 처리 (Treatment) | 주요 활용처 (Use Cases) |
| :--- | :--- | :--- |
| **Flat Layer** | 그림자 없음, `white` 또는 `gray.25/50` 단색 표면 | 대시보드 전체 베이스 백드롭, 테이블 로우 라인 |
| **Elevated Layer 1 (xs)** | `dropShadow.xs` (y:2, blur:8, spread:-1) | 인풋 필드 포커스 상태, 툴팁, 소형 배지 카드 |
| **Elevated Layer 2 (s)** | `dropShadow.s` (y:4, blur:12, spread:0) | 대시보드 내 위젯 모듈 카드, 드롭다운 선택창 |
| **Elevated Layer 3 (m)** | `dropShadow.m` (y:6, blur:24, spread:0) | 슬라이드 오버 내비게이션, 프리뷰 컨테이너 |
| **Elevated Layer 4 (lg / xlg)** | `dropShadow.lg` / `xlg` | 메인 시스템 모달, 알림 팝업창, 가이드 마법사 |

## 형태 및 라운드 (Shapes & Border Radius)

관리자가 다루는 데이터 영역과 사용자가 커스텀빌딩하는 영역을 매끄럽게 구성하는 라운드 스케일입니다.

* **`xs` (4px / `0.25rem`)**: 상태 표시 Badge, 소형 검색 바 입력창 테두리, 체크박스.
* **`s` (8px / `0.5rem`)**: 테이블 셀 로우(Row), 일반 버튼 UI, 드롭다운 컴포넌트 목록.
* **`m` (12px / `0.75rem`)**: **Cherpa의 표준 카드 라운드값.** CMS 관리자 대시보드 위젯, 설정 세션 블록.
* **`lg` (20px / `1.25rem`)**: 팝업 모달창 전체 프레임, 맞춤형 웹 제작 템플릿 프리뷰 카드.
* **`xxlg` (32px / `2rem`)**: 브랜드 핵심 기능을 트리거하는 **`button-primary` 전용 Pill 라운드값**.
* **`full` (1600px / `100rem`)**: 완전한 원형 상태 지표 컨트롤러, 사용자 아바타 서클.

## 주요 컴포넌트 규칙 (Key Components)

### **`button-primary`**
* **디자인 사양**: `primary.600`(`#3070E2`) 바탕에 `white` 텍스트를 조합하며, `borderRadius.xxlg`(32px Pill) 형태를 적용합니다.
* **용도**: "웹사이트 생성하기", "고객 데이터 내보내기", "설정 저장" 등 비즈니스에서 가장 중요한 단 하나의 핵심 액션에만 엄격하게 한정 적용합니다.

### **`button-secondary`**
* **디자인 사양**: 투명한 배경에 `gray.300` 아웃라인을 적용하거나 `gray.900` 바탕에 `white` 텍스트를 배치합니다.
* **용도**: "취소", "임시저장", "상세 보기" 등 일반적인 보조 액션 유도에 적용하여 프라이머리 버튼의 시각적 지배력을 해치지 않도록 조절합니다.

### **`management-widget-card`**
* **디자인 사양**: `gray.25` 또는 `blueGray.50` 배경 위에 `dropShadow.s`를 적용하고 테두리는 `gray.200` 1px 선으로 마감합니다. 라운드값은 `m`(12px)을 채택합니다.
* **용도**: CMS/CRM 관리 화면 내에서 통계 차트, 리드 관리 테이블, 빌더 제어 패널을 안정감 있게 수용하는 표준 컨테이너입니다.

## 디자인 Do's & Don'ts

### Do (권장 사항)
* **정답**: 화면의 85% 이상은 화이트, 블랙, 그레이 톤의 무채색 조합으로 레이아웃을 마감하여 데이터 가독성을 최우선으로 확보하세요.
* **정답**: 사용자의 액션이 최종 완료되는 지점이나 결정적인 전환점 스폿에만 정밀하게 타격하듯 `primary.600`을 매핑하세요.
* **정답**: 레이어가 겹치는 복잡한 대시보드 화면에서는 `dropShadow` 토큰 스케일을 준수하여 명확한 깊이감을 표현하세요.
* **정답**: 서체 타이포그래피 배치 시 오직 지정된 `SUIT Variable` 규칙표의 사이즈와 속성만 바인딩하여 사용하세요.

### Don't (금지 사항)
* **오답**: 단순 장식이나 눈에 띄게 만들고 싶다는 이유로 일반 컴포넌트 카드나 섹션 넓은 배경 전체에 블루 컬러를 채워 넣지 마세요.
* **오답**: 가이드에 명시되지 않은 임의의 원색 계열이나 채도가 높은 그라데이션을 UI 표면 요소로 남용하지 마세요.
* **오답**: 섀도우 값이나 라운드 값을 토큰에 없는 임의의 수치로 가공해 쓰지 마세요. 무조건 시스템 토큰 풀 내에서 해결해야 합니다.
